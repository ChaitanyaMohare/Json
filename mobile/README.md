# RouteGuard - Mobile App (Android)

AI-powered road incident intelligence and safer-navigation mobile application for riders.

## Tech Stack
- **Language:** Kotlin
- **IDE:** Android Studio (Ladybug / Iguana / Koala recommended)
- **Min SDK:** Android 8.0 (API level 26+)
- **Target SDK:** Android 14+ (API level 34+)
- **Map & Routing:** Mapbox Maps SDK & Mapbox Navigation SDK for Android

## Setup Instructions (Pending Environment Configuration)
1. Open Android Studio.
2. Ensure Android SDK 34+ and build tools are installed.
3. Configure your Mapbox Access Token and Downloads Secret Token in `gradle.properties` / `local.properties`.
4. Import / initialize the project when Android development environment is ready.
